# Control Electoral para Organización Política

Aplicación móvil (React Native + Expo, Android) para gestionar el escrutinio el día de las elecciones.
Examen I – Desarrollo de Aplicaciones Móviles.

## Requisitos

- Node.js (LTS recomendado) y npm
- Git
- Cuenta en Expo (para EAS Build)

## Comandos

```bash
npm install            # instalar dependencias
npm start              # servidor de desarrollo (usa el development build)
npm run typecheck      # verificación de tipos
npm run build:dev      # APK de development build (EAS)
npm run build:apk      # APK instalable para entrega (EAS, perfil preview)
```

> Instalar dependencias siempre con `npx expo install <paquete>` para obtener versiones compatibles con el SDK.
